      ⚙ Ajustes de conexión y modelo

      Elige si hablas con un servidor local u otra API compatible con el formato de OpenAI (LM Studio, Ollama, vLLM, OpenAI, Groq, OpenRouter…) o directamente con la API de Anthropic usando tu propia clave.
      Cualquier servidor u API que exponga /v1/models y /v1/chat/completions en formato OpenAI. Ollama la expone en http://localhost:11434/v1 (sin necesitar clave). Si la conexión falla con un error de red (no un HTTP concreto), revisa que el servidor esté iniciado y que CORS esté habilitado; si el servidor SÍ responde con un HTTP de error (401/402/404/429...), el problema es la clave, el saldo o el nombre del modelo, no CORS — mira el aviso que aparece debajo del selector de proveedor tras conectar.
      Se envía como cabecera Authorization: Bearer. No hace falta para LM Studio ni Ollama en local; es obligatoria para OpenAI y para cualquiera de las APIs en la nube de los chips de arriba.
      Las peticiones salen directas desde este navegador hacia api.anthropic.com (sin servidor intermedio), usando la cabecera oficial que Anthropic ofrece para uso desde el navegador. La clave se guarda solo en este navegador (localStorage): trátala como una contraseña. Consíguela en console.anthropic.com. Modelos orientativos: claude-sonnet-5 (recomendado), claude-opus-4-8, claude-haiku-4-5-20251001.
      "Guardar claves" descarga un archivo .json pequeño con la URL, la clave y el modelo de cada proveedor que hayas usado (cualquiera de los chips de arriba, más Anthropic), para poder restaurarlos después con "Cargar claves" — en este navegador, en otro, o tras borrar los datos del sitio. Además, cambiar entre chips ya recuerda automáticamente la clave que hayas guardado antes para cada uno. Este archivo contiene claves secretas: si no lo cifras con contraseña, guárdalo en un sitio privado, no lo subas a repositorios públicos ni lo compartas.

      0.90
      Tamaño de contexto aproximado que admite el proveedor/modelo activo (system prompt + historial + margen de salida). Ejemplos orientativos: modelos locales pequeños 4096-8192, modelos abiertos en la nube 8000-32000, Claude 200000. El contador junto al selector de modelo avisa cuando la conversación se acerca a este límite, y los turnos más antiguos se recortan automáticamente del envío (no del chat visible) si no caben, para evitar el error "context_length_exceeded".
      Cuántas pasadas de auditoría/corrección encadena el botón 🔁 Revisión iterativa del editor: 1 = solo una corrección directa; 2 (recomendado) añade una segunda opinión independiente que confirma o sigue puliendo; 3 = máxima insistencia, más lento y más peticiones al modelo.
      Este prompt se envía siempre como primer mensaje del sistema. Ya incluye contexto específico de Mint 22.3 (Cinnamon, Nemo, sin Snap por defecto, mintupdate-cli, etc.) y refuerza que el modelo devuelva el script completo en un único bloque de código.
      Se envía como mensaje de sistema adicional en cada petición, junto al system prompt, para anclar los scripts a tu máquina real. Déjalo vacío si no lo necesitas — no se borra al pulsar "Restaurar por defecto".
